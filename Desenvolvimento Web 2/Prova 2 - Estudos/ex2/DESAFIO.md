# Exercício 01 — Cartão de perfil

## Objetivos
1. Conforme a pessoa digitar em `nomePerfil`, atualizar `nomePreview` imediatamente.
2. Fazer o mesmo entre `cursoPerfil` e `cursoPreview`.
3. Quando `temaPerfil` mudar, trocar a classe do cartão para `tema-azul`, `tema-verde` ou `tema-roxo`.
4. Quando desmarcar `detalhesPerfil`, esconder `detalhesPreview`; ao marcar novamente, mostrar.

## Dicas
- Para digitação, experimente o evento `input`.
- Para um `<select>` e um checkbox, experimente `change`.
- Use `textContent`, `checked`, `hidden` e `classList`.
- Cuidado para não remover outras classes importantes do cartão.

**Extra:** se o nome estiver vazio, mostre `Seu nome` no cartão.
